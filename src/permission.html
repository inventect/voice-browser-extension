● voice browser — microphone permission

one-time microphone access

Chrome cannot show the microphone prompt inside a side panel, so it is requested here once. The permission belongs to the extension (chrome-extension://…), so afterwards the side panel can listen. Choose Allow (not "Allow this time") in the prompt.

Requesting microphone access…

If the prompt does not appear: click the icon left of the address bar → Site settings → Microphone → Allow, or use the button above. Then go back to the side panel and press Start mic (it starts automatically when it sees the grant).
